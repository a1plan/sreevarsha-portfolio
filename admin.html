/ Go live

Publish to GitHub.

Keep your portfolio hosted free on GitHub Pages. This site uses plain HTML, CSS and JavaScript, with no build step.

Security: Never add your token to a file or commit. Your token is used only for GitHub API requests made from this browser and is not saved to local storage. This editor itself is publicly accessible when hosted; the GitHub token—not the page URL—controls publishing authority. Use a fine-grained, repository-scoped token with Contents: Read and write, and revoke it if exposed.

Connect your repository

First, upload the site files to a public GitHub repository and enable Pages: Settings → Pages → Deploy from a branch → main / (root). Then enter your repo details here. The editor will commit changes directly to assets/js/data.js.

Backup & local editing

Local drafts stay in this browser only. Export a JSON backup if you want to save it outside GitHub, or import one you've edited elsewhere. Changes aren't visible publicly until published to GitHub.

Hosting & upload considerations

  • Single-file uploads through this editor are limited to 18 MB for browser reliability. Use an external link for large video, VR, or complete course packages.
  • PDF and Office files download; video and image files can open in a new tab. A ZIP can contain a SCORM package, but GitHub Pages is not an LMS and will not track SCORM completion.
  • GitHub Pages is appropriate for your professional portfolio. GitHub expressly limits using Pages as an e-commerce or SaaS hosting service.
  • GitHub Pages will publicly expose any files you upload. Check client confidentiality and rights before publishing.
